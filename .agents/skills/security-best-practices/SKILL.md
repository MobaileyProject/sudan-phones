# security-best-practices

Identify actual languages/frameworks and read the relevant files from the
[pinned security guide](upstream/GUIDE.md) and upstream/references/. This upstream
skill covers Python, JavaScript/TypeScript and Go; it does not certify Kotlin or
native Android security. Assess those separately with platform-specific evidence.

For this marketplace focus the requested scope on store ownership, founder powers,
session handling, private evidence and public-response boundaries. Cite paths/lines,
conditions and concrete impact for findings; distinguish planned controls from
implemented ones. Findings do not authorize unrelated hardening, production changes,
external scanning or uploading private code to another service. Follow the user's
current task authorization and AGENTS.md; record reproduced defects accurately.
Deliver scoped findings, fixes/tests when authorized, and explicit coverage limits.
The repository AGENTS.md is the shared operating contract. Use this skill only
for its matching task; do not preload the entire skill collection.
