# BUG-2026-013: Backend review regression

Independent read-only review of revision 63da7d7 identified this behavior.
Root cause: Mutation authorization trusted a membership read before waiting for the store lock, allowing a revoked member to commit afterward.

Regression: `backend/core/tests/test_concurrency.py::InventoryConcurrencyTests.test_revoked_staff_cannot_write_after_waiting_for_store_lock`. The named test reproduced the missing behavior before the
fix against real services/PostgreSQL, with only provider boundaries replaced.
No real customer data, credentials or private evidence was used.

Expected correction: Re-read current membership and role after acquiring the store lock.
Final resolution requires the named regression and full project suite to pass;
results are recorded with the fixing PR and backend acceptance evidence.
