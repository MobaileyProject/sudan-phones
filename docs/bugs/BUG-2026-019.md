# BUG-2026-019: Delegated role revocation during a store-lock wait

Follow-up audit of the membership race found the same stale authorization pattern
in delegated moderation/verification. A real PostgreSQL writer waited on a store
lock while the founder removed its role permission through save_role. Before the
fix it committed removal; the regression expected 403. After the fix the write is
denied and the listing stays published. No provider or database behavior is mocked.
Full verification is recorded in the fixing PR and backend acceptance evidence.
