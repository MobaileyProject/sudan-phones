# BUG-2026-003: Historical CI failures appear as active defects

## Reproduction and evidence

The first live sync imported failed runs 43249687936 and 43257649891 as Backlog.
`gh run list --branch main` showed newer successful runs of the same workflow,
including 43773944527. These rows did not establish active defects.

A regression fixture containing CI success 20, older CI failure 19, and an
independent workflow failure 18 expected only `ci:18`. Before the fix it returned
`ci:19` as well. The test failed with that exact list mismatch, then passed after
filtering the newest completed run per workflow.

## Resolution

The implementation fix is part of feature/slack-agent-automation. Historical rows
are preserved with an explanatory result rather than deleted. Final tests and
live correction evidence are in docs/STATE.md. Source windows remain bounded.
